# Ресерч

## Как устроено сейчас
- Живые экраны — iframe страниц через шлюз (`lib/gateway`, свой порт → другой origin). В каждую HTML-страницу шлюз ставит `inject-script.ts`: высота страницы, 401/403, пересылка колеса. Связь — postMessage, iframe находится по `data-lam-node-iframe`.
- iframe в ноде без событий мыши (`pointer-events: none`), кроме режима «взаимодействие» (двойной клик).
- Снимок: `snapshot-store` (машина фаз idle → opening → selecting → capturing), `tab-grabber` (getDisplayMedia своей вкладки, кроп по прямоугольнику окна), `SnapshotOverlay` (выделение мышью). Alt+Shift+S — снимок для замечания.
- Замечание (`FeedbackPanel`): текст + важность → «Копировать промпт» / «Скачать JSON». Ничего не хранится, привязки к компоненту нет.
- MCP (`packages/mcp-server`): submit_feedback/list_feedback (файлы в .lam-feedback), get_visualizer_state, request_snapshot/get_snapshot; тот же набор на dev-сервере `POST /mcp`. Правило папки обмена — один писатель на файл.
- Карта кода (`doc.code.symbols`): имя, вид, файл, строка — по имени компонента можно найти файл:строку.
- korbor: React 19.2 + Vite 8. В React 19 у fiber нет `_debugSource`, есть `_debugStack` (стек места создания JSX) и `_debugOwner`; имя компонента — `type.name`/`displayName`.

## Покрытие (что система замечаний должна уметь)
| Нужно | Было | Делаем |
|---|---|---|
| Выбор компонента курсором в живом экране | нет (только область) | пикер в скрипте шлюза |
| Привязка: селектор, путь DOM, текст, координаты | нет | да |
| Снимок области | да (ручное выделение) | автоматически по рамке компонента тем же TabGrabber |
| Исходник компонента | нет | цепочка компонентов из fiber + файл:строка из карты кода, `_debugStack` как запасной |
| Хранение замечаний | нет (только экспорт) | .lam-feedback/comments, события только дописываются |
| Статусы открыт/исправлен | нет | да, плюс «открыть снова» |
| Ответ агента с файлами и коммитом | нет | add_change_note |
| Метки на ноде | нет | да |
| Панель экрана с ветками | нет | вместо формы FeedbackPanel |
| Общий список с фильтрами и переходом | нет | панель «Замечания» |
| Голосовой ввод офлайн | нет | Whisper (transformers.js), WebGPU → WASM |
| Управление моделью (скачать, прогресс, удалить) | нет | да |
| Замечание без живого iframe (снимок/заглушка) | — | не покрываем: пикер работает только в живой ноде; сказано в подсказке |
| Несколько пользователей, синхронизация | нет | вне рамок |

## Дыры, замеченные по пути
- Метки по координатам страницы съезжают, если в окне ноды страница прокручена (режим «окно»). В режиме «целиком» совпадают.
