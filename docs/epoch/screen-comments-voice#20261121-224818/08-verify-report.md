## Сценарий целиком (comments.e2e)

Выбор экрана → C → наведение и клик по компоненту в живой странице → поле у компонента (снимок, компонент, файл:строка) →
текст → Enter → метка на ноде, число в шапке → MCP `list_comments` видит привязку (селектор, компонент, исходник .tsx),
`get_comment` даёт путь к снимку → `add_change_note` → в UI ответ ИИ и статус «Исправлено» → «Открыть снова» видно агенту →
общий список: поиск, фильтры статуса, переход фокусирует ветку.

## Голос (voice.e2e, проект voice)

Микрофон Chromium читает `e2e/fixtures/voice-ru.wav` (macOS say, «Кнопка отклика налезает на заголовок карточки»).
- Первое использование: окно предлагает модель 80 МБ, язык «Русский», текст о локальности → «Скачать» → прогресс →
  «Готово» → удержание ⌥ → живой черновик → в поле «Кнутка отклика нарезает на заголовок карточки.» — проверка по словам
  «заголов», «карточк» → правка → сохранено.
- Модель с диска: удержание кнопки, внешняя сеть браузера отрезана — текст распознан, окна нет.

## Не сделано

- Распознавание на WebGPU в e2e не проверено: в headless Chromium WebGPU недоступен, идёт WASM. Режим выбирается сам.
- Узбекский язык проверен только выбором в окне; аудио на узбекском в фикстурах нет.
- Метки ставятся по координатам документа страницы: если страница прокручена внутри своего контейнера, метка смещается.
