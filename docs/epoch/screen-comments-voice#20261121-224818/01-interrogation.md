# Вопросы

Задача пришла от координатора Orca с полным ТЗ; вопросов, без ответа на которые нельзя начать, нет.
Решения по неоднозначным местам — в 06-decisions (с причинами), чтобы владелец мог оспорить.

- «Переиспользуй существующий пикер компонентов» — в коде есть только выделение **области** мышью (SnapshotOverlay + TabGrabber). Пикера элемента под курсором нет. Решение: снимок берём тем же TabGrabber, а выбор элемента добавляем в скрипт шлюза, который уже стоит в каждой странице (inject-script). Второго механизма снимка не появляется.
