- [x] Порядок событий ветки зависел от часов: ответ и статус, записанные в одну миллисекунду, сортировались случайно (тест comment-tools падал 1 раз из ~5). Причина — ключ сортировки «время + случайное имя файла». Исправлено: у события номер `seq` (created — 0, дальше max+1), время — только для гонки двух писателей.

- [x] Строка исходника компонента была строкой кода, который отдал Vite, а не исходника (VacancyFeedCard.tsx:321 при 239 строках). Исправлено: страница читает sourcemap своего модуля и переводит позицию (`originalPosition`, тест на VLQ).
- [x] Выбор компонента иногда не открывал поле: `requestVideoFrameCallback` ждёт новый кадр, неподвижная вкладка его не шлёт — снимок висел. Исправлено: ждём кадр не дольше 250 мс, иначе берём последний.
- [x] Первая загрузка модели падала «network error»: два одновременных запроса одного файла писали в один `.part`, второй `rename` рвал ответ. Тест с перекрывающимися запросами красный → зелёный после уникального имени `.part`.

- [x] Пустая левая панель и кнопки в панели экрана закрывали ноду и мини-карту при 1024×700 (overlap.e2e). Исправлено: кнопка в шапке ноды, «Область» в подсказке, левая панель — только при ветках.
