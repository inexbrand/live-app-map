# Бриф: замечания к экранам, голос, ответы ИИ

## Цель
Быстро оставлять замечание к компоненту живого экрана в визуализаторе (текстом или голосом, офлайн), а агенту — читать их по MCP, отвечать, что изменил, и закрывать. Всё видно в интерфейсе ветками «замечание → ответ ИИ → статус».

## Готово когда
- [ ] Наведение на компонент внутри живого экрана подсвечивает его; клик открывает поле замечания у компонента. Привязка: селектор, путь DOM, текст, координаты, снимок области, компонент React и файл:строка.
- [ ] Голос: «держи и говори» (кнопка и клавиша), живой черновик, правка до отправки. Модель Whisper скачивается по согласию (размер, язык ru/uz/en, прогресс), хранится в браузере и на диске, удаляется; распознавание офлайн, звук никуда не уходит.
- [ ] MCP: list_comments, get_comment, add_change_note, resolve_comment, reopen_comment; хранение в .lam-feedback/comments (вне git), формат описан.
- [ ] Метки на ноде, панель экрана с ветками, общий список замечаний с фильтрами и переходом к компоненту.
- [ ] e2e сценария (выбор → голос/текст → MCP ответ → видно в UI), тест распознавания реального аудио локальной моделью, скриншоты, весь e2e зелёный, typecheck чистый.
- [ ] PR в master, не слит.

## Вне рамок
- Синхронизация замечаний между машинами, учётные записи авторов.
- Облачное распознавание (запрещено задачей).
