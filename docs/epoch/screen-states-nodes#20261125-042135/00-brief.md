# screen-states-nodes — состояния экранов узлами на карте

Зона тиммейта «states» (лид раздал задачу 2026-11-25, эпоха-родитель project-states-sdk#20261125-041817).

Цель: визуализатор показывает все состояния экранов из `<проект>/.live-app-map/states.ts` (контракт LamScreenState) и поля states карты — отдельными узлами рядом с экраном. Каждый узел — настоящая страница: роль состояния (профиль входа), `?lam_state=<экран>/<состояние>` (рантайм sdk подменяет API), шаги (click/fill/press/waitFor/scroll) после загрузки — и в трансляции, и в снимке шлюза.

Готово, когда: тесты schema, stream-service (настоящий headless Helium), раскладка; typecheck визуализатора; живая проверка на своём порту 4431 с картой korbor — узлы видны, роль и lam_state в адресе, шаг «клик» открывает модалку на кадре.
