# Decisions

1. **Снимок = Screen Capture API текущей вкладки**, а не рисование DOM в canvas: только так в кадр попадают cross-origin iframe. Поток открывается до выделения — панель Chrome «Вы показываете вкладку» сдвигает страницу.
2. **Просьба агента требует клика пользователя**: getDisplayMedia без жеста запрещён браузером. Карточка «Агент просит снимок» → «Снять». Просьбы живут 10 минут.
3. **Канал агент ↔ визуализатор — файлы в `.lam-feedback/agent/`**, у каждого файла один писатель (состояние и снимки пишет dev-сервер, просьбу — MCP-tool). Атомарная запись tmp → rename. Папка — в корне монорепо (`resolveLamDir`), иначе vite (cwd apps/visualizer-spa) и `bun run mcp` (cwd корень) смотрели бы в разные места.
4. **mcp-server разбит на ядро** (rpc, tools, agent-state, lam-dir) и тонкий stdio-транспорт; HTTP-эндпоинт `/mcp` визуализатора использует то же ядро.
5. **error-reports без SMTP**: почтовой зависимости в репо нет; отчёты в `error-reports.jsonl` + консоль dev-сервера.
6. **Каталог карт**: id = имя файла без `.liveappmap.json`; подпись и baseUrl Korbor — из `KORBOR_PRESETS` (порты dev-серверов), прочие — из JSON карты. index.json перезаписывается только при изменении.
7. **Нет высоты viewport при конвертации** → `DEVICE_HEIGHT_FALLBACK` + heightMode=auto (визуализатор измерит), а не тихая фиксированная высота.
8. **vite под Bun** (`bun --bun vite`): Node-загрузчик конфига не резолвит workspace-пакеты, отданные как `.ts`.
9. **/__lam_proxy/https** — свой middleware: у vite proxy нет `router`, старый код всегда ходил на 127.0.0.1:443.
10. **Защита эндпоинтов**: не-локальный Origin → 403 (dev-сервер слушает все интерфейсы).
