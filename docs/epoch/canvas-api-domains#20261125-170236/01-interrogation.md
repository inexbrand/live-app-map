# 01 — допрос

Скрин: веер пунктиров в левую точку `@korbor/api`, группа «Сервисы бэкенда 20» с нулями.

Пользователь: «можешь исправить на экранах что у нас с одного всё выходит да как бы», «в экранах это».

Я предложил: 1) рёбра к API только у выбранного экрана; 2) одно ребро на пару приложение → сервис; 3) развести точки входа. Спросил про сервисы с нулями.

Ответ дословно: «я хочу чтобы у нас было как бы по роутам например там /v1/auth и все экраны которые делают этот запрос показывались да как бы».

Трактовка: нижняя группа — домены роутов (как в виде «API», память api-domains-audiences), ребро экран → домен, выбор домена показывает все его экраны. Сервисы-пакеты с нулями уходят вместе с сервисами.
