# 06 — решения

- Ноды доменов — синтетические `AppMapNode` вида `service` с id `api-domain:<имя>` и `metadata.apiDomain`: весь путь холста (фильтр, раскладка, группа) уже работает с нодами карты, отдельный тип ноды потребовал бы переписать раскладку. Отличие — в `ServiceNode` по `apiDomain`.
- Домены — та же `apiDomains`, что в виде «API» (одно решение в одном месте).
- Рёбра к API в покое скрыты (`hidden`): на korbor 186 пар экран–домен, при показе всех — та же каша. Выбран экран — его домены, выбран домен — все его экраны.
- Сервисы без роутов (пакеты i18n, logger…) с холста ушли: при наличии роутов в карте все сервисы заменяются доменами. Карта без роутов — сервисы как раньше.
- Заголовок группы — «API».
