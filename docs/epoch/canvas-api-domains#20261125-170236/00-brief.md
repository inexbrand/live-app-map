# 00 — бриф

**Цель.** На холсте «Экраны» связь экранов с бэкендом показывать по доменам роутов API (`auth`, `vacancies`, …), а не одной карточкой сервиса `@korbor/api`, в левую точку которой сходились все 76 пунктирных линий веером поверх заголовка группы.

**Готово, когда:**
- в нижней группе холста — карточки доменов API (имя, общий префикс пути, число роутов и экранов), а не сервисы и пакеты с нулями;
- ребро «экран → домен» одно на пару, подпись — сколько роутов домена экран вызывает;
- в покое линии к API не рисуются; выбран экран — видны его домены; выбран домен — видны все экраны, которые его вызывают;
- тесты на реальном срезе korbor зелёные, живая проверка на korbor скриншотом.

**Вне рамок:** панель кода по клику на домен (доска домена), вид «API».
