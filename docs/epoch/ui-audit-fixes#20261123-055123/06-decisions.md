# Decisions

- Кнопки карточки — по состоянию наведения (не CSS :hover): в покое кнопок нет в DOM,
  у выбранной есть всегда (e2e замечаний ищут кнопку у выбранной).
- Обзор — через DOM (класс и CSS-переменная на хосте), а не state: зум идёт каждый кадр,
  перерисовка нод на каждый кадр дорога. Порог 0.4. Подпись раздела в обзоре — над рамкой;
  для рамки снят `contain: paint`, иначе подпись обрезалась.
- «Источники» удалены целиком: всё есть в селекте. Поле файла осталось в шапке для пункта
  «Открыть JSON».
- Ошибка загрузки — только баннер: тост гаснет через 4 с и дублировал текст.
- Значки API — отличие от большинства карты (`usualChecks`): у korbor почти все роуты
  с проверками, значок нужен там, где проверки нет.
- 09-bugs: блок «Пункты» главный, текст файла не удалён, а свёрнут — в файле бывает текст
  кроме пунктов.
- Числа документации: данные не менялись, добавлена строка «Показан снимок из карты (эпох: N) …»
  пока диск не прочитан или чтение не удалось. Три e2e, написанные под снимок, явно
  отключают чтение диска — иначе зависели от гонки.
- Граф: по умолчанию эпохи (с файлами по раскрытию), заметки, руководства; «показать все» —
  все типы.

Вне рамок, замечено по ходу (в аудите — среди 47 остальных находок):
- тост «Miniapp: в БД нет user с telegramId — iframe останется без auth» — жаргон;
- в панели экрана «Глобальная роль» повторяет «Смотреть как» из настроек, «Клики в iframe» — жаргон.
