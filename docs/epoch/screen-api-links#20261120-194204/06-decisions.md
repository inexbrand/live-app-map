# Решения

- **Символьное вычисление вместо регулярок.** Аргументы вызова вычисляются через checker: константы, шаблоны, enum, объекты, деструктуризация, билдеры запросов. Каждая часть строки помнит место вызова, где появилась: вызов обёртки засчитывается месту, где задан литерал с `/`, — поэтому `api.get('/x')` даёт вызов у вызывающего, а сама обёртка (`fetch(${BASE}${path})`) — нет.
- **Именованный клиент как запасной путь.** korbor ходит в API через интерфейс клиента с фабрикой поверх внедрённого `fetchWithAuth` — до fetch не дойти. Если реализацию метода не разрешить, `api.post('/x')`, `apiClient.request('/x', { method })`, `client.request({ path, method })` считаются вызовом, когда имя получателя похоже на клиент и второй аргумент не функция (иначе это `app.get('/x', handler)`).
- **База из env — только путь.** Из `VITE_API_URL=https://host/api` в карту попадает `/api`; origin и значения не сохраняются.
- **Матчинг строгий.** Литерал = литерал, параметр роута принимает любой сегмент, динамический сегмент вызова в литерал роута не попадает (`/api/v1/:surface/…` остаётся несопоставленным — честно, а не наугад employer/recruiter).
- **Фабрики роутов.** Путь роута из параметра функции (`.get(basePath)`) вычисляется в каждом месте вызова фабрики: korbor +54 роута, сопоставлено 270 вместо 234.
- **Экраны React Router.** Нода RR указывает на конфиг роутов; экран ищется по объекту роута с тем же путём (`[id]` = `:id`), обход — от `element/Component/lazy`. Табы без элемента (`element: null`) остаются без вызовов.
- **Фабрики клиентов не обходятся целиком** (функция, возвращающая объект из 2+ функций): экрану достаются только методы, к которым он обращается; метод по имени без типа (`useMemo(() => createApi())`) — только если имя есть не больше чем у двух интерфейсов и в том же сервисе.
- **Viewer-формат** теперь хранит `project.root` и `source` ноды — без них панель кода экрана в liveappmap-картах была пустой (ошибка была и до задачи).
- Отступление: `value-evaluator.ts` 374 строки (> 300) — один класс вычислителя, деление по методам ухудшит чтение; `routes.ts` 353 строки был таким до задачи.
