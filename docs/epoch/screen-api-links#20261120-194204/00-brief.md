# Brief — связь «экран → роут API»

## Цель
Сканер находит в коде экранов (Next, React Router, Vite miniapp) вызовы API — fetch, axios, ky, Eden treaty, Hono RPC, обёртки вида `api.get`/`apiFetch`/`client.request` — и сопоставляет их с роутами scanner-source (метод + путь с параметрами, база из env). В карте: экран → роут → таблицы. В визуализаторе у экрана видно, какие роуты он вызывает, переход к роуту; несопоставленные — отдельно.

## Готово когда
- [ ] `CodeModel.apiCalls` (метод, путь, клиент, место, routeId?) и `CodeModel.screens` (файл экрана → вызовы, достижимые из него).
- [ ] Рёбра `kind: 'api'` экран → сервис в карте `scan --code-dir`.
- [ ] Панель экрана: «Вызовы API» с роутом, таблицами и кнопкой перехода к роуту; «Не сопоставлены».
- [ ] Тесты на фикстуре зовут настоящий сканер; числа по korbor и vpn-saas (найдено / сопоставлено).
- [ ] PR в inexbrand/live-app-map, готов к мерджу.

## Вне scope
- gRPC, WebSocket, GraphQL.
- Вызовы, URL которых целиком приходит извне (из ответа сервера, из пропсов без литерала в коде).
