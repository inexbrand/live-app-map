# Бриф: UX-переделка визуализатора

Цель: визуализатор live-app-map (apps/visualizer-spa) удобен, чтобы понимать проект, закрывать задачи и проверять экраны: легко читается, короткие сценарии, единая навигация между видами, глобальный поиск, горячие клавиши, документация графом в духе Obsidian.

Готово, когда:
- аудит всех видов на korbor-all со скриншотами «до» и разделом «Покрытие» (02-research);
- сценарии «понять проект», «закрыть задачу», «проверить» короче по кликам; адрес страницы хранит вид и выбранное, работают «назад/вперёд», есть хлебные крошки;
- глобальный поиск по экранам, роутам, таблицам, эпохам, документам и файлам (Ctrl/⌘+K), горячие клавиши видов и справка по ним;
- граф документации: эпохи, файлы эпох, заметки, руководства и объекты карты, на которые они ссылаются; раскрытие по клику, фильтры по типу и готовности, подсветка соседей, поиск, локальный граф рядом с текстом, canvas;
- светлая тема и выверенный контраст тёмной, понятные пустые состояния и ошибки;
- скриншоты «после», e2e на сценарии и граф, весь e2e зелёный, typecheck чистый; PR в master.

Вне рамок: логика сканера и данные вида «API» (задача 11, другой агент).
