# Исследование и аудит

Аудит на korbor-all (111 экранов, 314 роутов, 74 таблицы, 26 эпох, 5 заметок, 7 руководств), 1600×1000, тёмная тема (светлой нет). Скриншоты «до»: `screens/before/`.

## Как устроено сейчас
- Шапка `MapToolbar.tsx` (675 строк): селект карты, 4 кнопки видов (`view-store.ts`), счётчик «live 6/6 · warm 0/2 · pin 1», «Источники», «Настройки», поиск экранов (шторка сверху, клавиша /, фильтрует только холст).
- Вид хранится в zustand (`view-store`) без адреса: перезагрузка или «назад» в браузере теряет вид, роут, таблицу, документ. Переходы между видами (`use-map-nav.ts`) есть, обратного пути нет.
- «Документация» (`DocsView.tsx`): список эпох слева, документ справа с вкладками файлов эпохи, ссылки из `кода` в роуты/таблицы/экраны (`resolveDocRef` в `@live-app-map/graph`). Графа нет.
- Стили: `global.css` (31 КБ, 58 зашитых hex), `views.css` (токены). Тема одна — тёмная, `color-scheme: dark`.

## Проблемы (глазами владельца)
### Общее и навигация
1. Нет адреса у состояния: ссылку на роут, таблицу, документ или эпоху не отправить, «назад» не работает, F5 сбрасывает вид.
2. Нет хлебных крошек: в «Базе данных» и «Документации» не видно, где ты и откуда пришёл.
3. Поиск ищет только экраны и только фильтром холста; роуты, таблицы, эпохи, файлы — у каждого вида свой поиск. Глобального нет.
4. Горячих клавиш почти нет (только /, Esc), подсказки по ним нет.
5. Селект карты показывает «Выберите карту…», когда карта открыта по ссылке `?map=` — состояние врёт (`before-screens.png`).
6. Счётчик «live 6/6 · warm 0/2 · pin 1» на виду у всех видов — служебные цифры бюджета iframe, человеку непонятны (правило владельца: служебное не держать на виду).
7. Пустой экран без карты говорит языком разработчика: «public/maps», «drag-and-drop», «селект карт», порт 4310 (`before-empty.png`).
### Экраны
8. Названия экранов обрезаются «applicat…», «vacanci…» при свободном месте — заголовок делит ряд с тремя кнопками-значками.
9. Подписи рёбер — белые плашки с чёрным текстом, самые яркие пятна на холсте; спорят с экранами.
### API
10. В карточке роута путь файла рвётся посреди числа «ingest.ts:7 / 6»; «Тело · Elysia t» — обрезанный тип (данные сканера, вне рамок, задача 11).
### База данных
11. Над списком таблиц пустая полоса ≈80 px: заголовок «Таблицы» опущен (`before-database.png`).
12. Описание таблицы — стена текста из комментария в коде на всю ширину, длина строки ≈150 знаков; читать тяжело.
13. Колонка «Ссылка» прижата к правому краю, оторвана от имени колонки на 1000 px; разделитель под каждой строкой.
14. «Пишут 33» — длинный плоский список с полными описаниями, нет свёртки.
### Документация
15. Фильтры готовности переносятся на две строки в колонке 320 px.
16. Строка эпохи — три строки мелкого текста, цель обрезана; готовность «готово · research» читается как мусор (статус INDEX и готовность 09-bugs склеены).
17. Открытые пункты в шапке эпохи — простой текст: из пункта нельзя перейти в код или на карту, хотя в нём упомянуты файлы.
18. Вкладок файлов эпохи 11 в ряд — нормально на 1600, на 1280 переносятся.
19. Нет графа связей: не видно, какие эпохи трогали роут или таблицу, какие документы ссылаются друг на друга.
### Читаемость
20. Нет светлой темы. В тёмной вторичный текст #a3a3a3 на #0a0a0a — 8:1, нормально; #737373 (размер вьюпорта, мета лога) — 4.3:1, ниже 4.5.
21. Базовый кегль 14/20 в документах — мелко для чтения длинных текстов; длина строки ок (720 px ≈ 90 знаков, лучше 70–75).

## База дизайна (прочитано)
preferences.md целиком; темы spacing-grouping, data-display, navigation, color-dark-theme, radius, buttons-cta, motion, dialogs-dropdowns, cards. Применимое: группировка отступами без линий (spacing-grouping 1–4), шкала 4/8/12/16/24/32; радиусы из одного набора 6/8 (radius); в тёмной теме поверхности светлее фона, вторичный текст читаемый ≥4.5:1, #121212-подобный фон вместо чистого чёрного (color-dark-theme); вкладки 2–5 и активная заметна (navigation); диалог закрывается крестиком, Esc и кликом вне окна (dialogs-dropdowns); анимация только смысловая, с prefers-reduced-motion (motion). Вкус: Medeo, без надзаголовков, без 01/02, без градиентных карточек, служебное не на виду, таблицы с поиском и сортировкой, «ровно».
