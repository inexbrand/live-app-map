# План тестов

Unit (bun test, реальные функции):
- `nav-location`: состояние вида → query → обратно; старые параметры map/baseUrl/role сохраняются; мусор в query отбрасывается.
- `global-search`: на настоящей карте korbor-all находит экран, роут, таблицу, эпоху, документ, файл; ранжирование: точное начало раньше подстроки.
- `doc-graph`: на korbor-all — узлы эпох, файлов, заметок, целей; рёбра «эпоха содержит файл», «документ ссылается на роут/таблицу/экран/файл/документ»; свёрнутая эпоха собирает рёбра своих файлов; фильтры типа и готовности; соседи; локальный граф глубины 1–2.
- Производительность: граф korbor-all строится и раскладывается (300 тиков d3-force) за бюджет.

e2e (Playwright, свой сервер :4311):
- навигация: вид и выбранное в адресе, «назад» возвращает прошлый вид, крошки ведут обратно;
- глобальный поиск ⌘K: роут → вид API с карточкой; таблица → БД; эпоха → документ; экран → холст;
- горячие клавиши 1–4, ?, t;
- сценарий «закрыть задачу»: фильтр «Не готово» → эпоха → открытый пункт → ссылка из пункта в код/карту;
- граф: canvas рисуется, фильтр типа меняет число узлов, клик по узлу открывает документ, локальный граф рядом с текстом;
- светлая тема переключается и сохраняется.
- весь существующий e2e зелёный.
