# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| Место в адресе: `view`, `route`, `table`, `doc`, `screen`, `docs=graph`; один писатель (store → history), popstate только применяет | ссылку можно отправить, «назад» и F5 работают; один писатель — нет гонки двух источников | react-router — лишняя зависимость ради пяти параметров |
| Смена экрана на холсте — replaceState, остальное — pushState | клики по экранам не засоряют историю | pushState на всё — «назад» листает десятки экранов |
| Граф на canvas 2D + d3-force, свой рендер | 544–785 узлов, сотни рёбер; SVG/React Flow на таком объёме тормозят, WebGL-библиотека — лишний вес | sigma.js / cytoscape — тяжёлые, свои стили, не на токенах темы |
| Форма узла = тип (круг, ромб, квадрат, прямоугольник), цвет — только для внимания (кольцо у незакрытой эпохи) | монохромная палитра проекта; цвет зарезервирован под «требует действия» | радуга по типам — шумно, против вкуса владельца |
| Эпохи на графе свёрнуты, клик раскрывает файлы | 241 файл эпох — шум при первом взгляде | всё раскрыто сразу — 785 узлов-ёжиков |
| Фильтр готовности выбирает документы-опоры, фильтр типа решает лишь, что показать | «только файлы кода» должен показать файлы из документов, а не пустоту | тип прячет и опоры — пустой граф (баг, найден e2e) |
| Камера следует за выбранным узлом, пока раскладка движется; рука отпускает | после раскрытия эпох выбранный узел уезжал из центра | центрировать один раз |
| «Закрыть задачу» — переход к пункту 09-bugs и ссылке на код/карту; отметку ставят в файле | визуализатор только читает карту, запись в чужой репозиторий — вне задачи | чекбокс в UI с записью файла — нужен dev-эндпоинт записи и права |
| Счётчик бюджета iframe — в «Настройках» | служебные цифры не держать на виду | оставить таблетку в шапке |
| Кнопки ноды 28 px в потоке, название до двух строк | название не режется и не перекрывается; кнопки поверх шапки перехватывали клик (упали 5 e2e) | кнопки поверх при наведении |
| Крошки до 1439 px — только «назад» и текущее место | на 1280 крошки сжимались до «Э. › M…» | многоточие у каждой |
| Вкладки файлов эпохи переносятся во вторую строку | все 11 видны сразу, без скрытой прокрутки | горизонтальная прокрутка — половина вкладок скрыта |
| Светлая тема — те же токены, `data-theme` на `html`, выбор в localStorage | один набор компонентов, тема не ветвит код | отдельные стили на тему |
| Reassure не подключён | в монорепо нет Jest/React Native Testing Library, Reassure требует их; скорость графа проверена unit-тестом на korbor-all (< 300 мс) | тащить Jest ради одного замера |
