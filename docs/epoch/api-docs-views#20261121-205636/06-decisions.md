# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| Текст документов хранится в карте (раздел `docs`, обрезка 200 000 символов на файл) | Карта самодостаточна: MCP и визуализатор читают одно и то же, работает без доступа к репо | Читать файлы с диска по запросу — MCP и статическая карта без исходников ломаются |
| Картинки эпох — dev-эндпоинт `/__lam_docs/asset` (только картинки, только внутри `docs/` корня) | 15+ PNG на эпоху раздули бы карту на мегабайты | base64 в карте; копирование в public |
| Готовность эпохи — по 09-bugs: неотмеченные `- [ ]` и пункты под «Open»; нет файла — отдельный статус | Правило docs-epoch: открытый пункт в 09-bugs — задача не готова | Доверять строке Status в INDEX — её часто не обновляют |
| Группировка роутов — по пути после `/api` и `vN`: раздел (admin, recruiter) → модуль | У korbor все 314 роутов в одном сервисе, деление по сервису ничего не даёт | Группы по файлу — у Elysia-плагинов это внутреннее устройство, не API |
| Доступ — эвристика по коду (сравнения role, права `a.b`, функции-проверки до глубины 1, хуки цепочки) | Схем авторизации нет в метаданных фреймворков; эвристика даёт 295 из 314 на korbor | Явная разметка в коде — korbor и vpn-saas её не используют |
| Фильтры вида «API» в view-store, а не в состоянии компонента | Переход роут → таблица → роут сбрасывал фильтры (поймано e2e) | — |
| Дизайн по совету design-expert: шкала 4/8/12/16/24/32, радиусы 6/8, без карточек-подложек, метод в слоте 56 px, GET серым, DELETE с обводкой; покрытие — список с полоской 2 px; вкладки эпохи словами без номеров | Требование брифа и антипаттерны владельца (без надзаголовков, 01/02, градиентных карточек) | Плитки метрик, точки-светофоры готовности |
| Код и пути — Medeo (`--mono` уже Medeo), вкладки по-русски («Бриф», «Баги») | Правило владельца: только Medeo; интерфейс русский | Моноширинный шрифт для путей |
