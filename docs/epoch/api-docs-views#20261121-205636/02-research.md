## Документация

- В карте раздела `docs` нет; ни сканер, ни визуализатор, ни MCP документов не видят.
- Объём: korbor — 26 эпох, 241 md, 470 КБ; vpn-saas — 163 эпохи, 1423 md, 4,6 МБ, 22 картинки;
  live-app-map — 5 эпох, 44 md, 72 КБ, 20 картинок.
- Форматы 09-bugs разные: `## Open`/`## Closed` (vpn-saas 61), `- [ ]`/`- [x]`, `- [закрыт]`,
  «Открытых нет.», пустой файл, «# Открытые вопросы» с чекбоксами. INDEX.md: `- Status: research|verified|done…`.
- Дата — суффикс папки `#YYYYMMDD-HHMMSS`.

## Что менять

- schema: `ApiRoute.input`, `ApiRoute.access`; новый раздел `DocsModel` (+ zod, convert).
- scanner-source: `route-input.ts`, `route-access.ts`.
- новый пакет `scanner-docs`: эпохи, заметки, руководства, разбор 09-bugs и INDEX.
- graph: `api-query.ts` (группы, фильтры), `docs-query.ts` (эпохи, поиск, ссылки).
- cli: `--code-dir` добавляет `docs`; korbor-скрипт; карта самого live-app-map.
- mcp-server: `list_epochs`, `get_epoch`, `search_docs`, `describe_api`; `get_route` с входом и доступом.
- visualizer-spa: `ApiView`, `DocsView` (react-markdown + remark-gfm), кнопки вида, dev-эндпоинт картинок.
