# Brief

## Цель

Вид «База данных» как Drizzle Studio: слева список таблиц, в центре ER-схема всех таблиц на React Flow,
снизу данные выбранной таблицы с правкой (тестовая БД), справа панель «Документация» / «Схема в коде».
Ширина и высота панелей меняются перетаскиванием.

## Готово когда

- [ ] Слева список таблиц с поиском; клик выбирает таблицу на схеме и открывает её данные снизу.
- [ ] В центре ER-схема: карточки всех таблиц с колонками, PK/FK отмечены, линии FK колонка→колонка, авто-раскладка dagre, карточки двигаются.
- [ ] Снизу сетка данных: страницы по 50, сортировка, фильтр «колонка = значение», правка ячеек по двойному клику, добавление строки, удаление выбранных; правки копятся, «Сохранить» — одной транзакцией, «Отменить» сбрасывает.
- [ ] Запись только при хосте БД localhost/127.0.0.1/::1, иначе только чтение с причиной на экране. Таблица без PK — только чтение.
- [ ] Адрес БД — `database: { urlEnv, envFile }` в `.live-app-map/config.ts`; поле не задано — вид пишет, что вписать; запасного адреса нет.
- [ ] Справа вкладка «Документация»: описание, колонки, кто ссылается, роуты чтения и записи с экранами, документы эпох, где упомянута таблица.
- [ ] Справа вкладка «Схема в коде»: исходный код объявления таблицы и кнопка «Предложить комментарий» (замечание агенту в общий список).
- [ ] Границы между панелями тянутся: ширина списка и правой панели, высота схемы и данных.
- [ ] Живая проверка на korbor (Postgres :16432): чтение, правка, вставка, удаление, откат.

## Вне scope

- Сложные фильтры (И/ИЛИ, операторы), экспорт CSV, SQL-консоль.
- БД кроме Postgres, Prisma.
