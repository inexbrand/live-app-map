# Test plan

- Сервер (`lib/db-data`): юнит — разбор config, проверка хоста, сборка SQL по запросу; живые — против Postgres korbor (`LAM_TEST_DATABASE_URL`): чтение страницы, сортировка, фильтр, транзакция вставки+правки+удаления, откат при ошибке, отказ записи на нелокальном хосте, 400 на неизвестную колонку.
- Сетка: DOM-тесты (happy-dom) с реальным http-сервером middleware или fetch к нему: правка ячейки → отметка изменения → «Сохранить» → запрос с правками.
- ER-схема: модель `erdModel(tables)` — ноды по таблицам, рёбра по FK; DOM — клик по карточке выбирает таблицу.
- Правая панель: «Документация» показывает эпохи из графа; «Схема в коде» показывает текст объявления из `/__lam_project/source`.
- Живая проверка: `bun run dev -- --project ../korbor`, вид «База данных» в Helium (helium-agent), снимок экрана.
