## Зона db-api

- Страница/сортировка/фильтр/total: `db-live.test.ts` «страница…» — настоящий Postgres, HTTP-сервер middleware.
- Транзакция удаления+правки+вставки, приведение текста к int/enum/jsonb/bool/timestamptz: «пакет…».
- Откат при ошибке в середине (дубль уникального) — 409, удаление и правка до неё не применились: «ошибка в середине пакета…».
- Параллельное удаление (строки нет) — 409 и откат; неверный текст для типа и varchar(3) — 400 от Postgres.
- Составной ключ, вставка из одних DEFAULT (identity).
- Отказы: без PK — 400, неизвестная колонка — 400, тело не по схеме — 400, нелокальный хост — 403, метод — 405, чужой origin — 403, проект не открыт — 404, нет database — off.
