# Brief

## Цель

Карта korbor в визуализаторе показывает настоящие экраны под ролями: без белых плиток, без регистрации вместо экранов мини-аппа, с реальными id в адресах.

## Готово когда

- [x] Мини-апп под recruiter/employer открывает экраны продукта, а не шаг регистрации.
- [x] Экраны админки в карте совпадают со снимками шлюза (нет белых при правильном снимке).
- [x] `POST /__lam_sessions/<роль>/sample-ids` у профилей автовхода — 200 с id из API.
- [x] Тесты на каждое исправление, typecheck, живая проверка на korbor; коммит и пуш.

## Вне scope

- dev-вход Payload CMS сайта (:16001) — решено оставить (пункт 4а).
- Демо-данные korbor (вакансии, сделки) и скилл генерации состояний — следующая задача, ждёт ответов пользователя.
