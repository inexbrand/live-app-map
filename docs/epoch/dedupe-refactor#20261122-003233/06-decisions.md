# Decisions

- Тесты с сокетами (middleware, шлюз, models) гонять без песочницы Claude Code: в ней localhost недоступен, это не регрессия.
- MCP: требования аргументов бросают Error, callTool превращает его в isError — текст ответа тот же, что у прежнего `return fail(...)`.
- dev-http: `endpointMiddleware` ловит исключение обработчика и отвечает JSON-ошибкой, только если ответ ещё не начат (`headersSent`). Раньше так делал только models; у остальных при исключении после начала ответа был бы повторный writeHead и необработанная ошибка. Нормальные ответы не изменились.
- error-reports проверяет метод раньше origin (GET с чужой страницы — 405, как в тесте), поэтому использует `endpointMiddleware` без встроенной проверки origin.
- sessions-middleware оставлен со своей проверкой origin: она строже (только сама страница визуализатора, не iframe шлюза).
- dev-api сохраняет прежние ветки: где раньше сетевая ошибка бросалась (setStatus замечаний, удаление модели, форма профиля), бросается и теперь (`status === null` → throw); где тело читалось и при не-2xx (список замечаний, размер модели, TLS-проверка) — берётся `anyBody`. Разница только в редком случае «не-2xx и тело не JSON»: раньше исключение разбора, теперь тело null → та же ветка «не по схеме / неизвестно». Выход из профиля: requestOk не бросает, поэтому список профилей обновляется и после сетевой ошибки (раньше — необработанный reject).
