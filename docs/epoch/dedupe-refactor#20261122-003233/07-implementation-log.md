- Исправлена утечка мока fetch в packages/react (45 ложных падений unit) — иначе нечем доказывать «поведение то же».

Переведены docs-live-client, map-compare-client, agent-bridge, report-client-error, comments/gateway/voice-store, SessionProfilesPanel, App (загрузка карты по ?map), MapToolbar (TLS-проверка).
