# 00 — Бриф: сканер исходников и комментариев

**Цель.** Карта проекта показывает не только экраны, но и сервисы бэкенда: роуты (метод, путь, обработчик и что он делает — из комментария), запросы в БД из обработчика, таблицы БД и экспортируемые функции/компоненты с их JSDoc.

**Готово, когда:**
- пакет `@live-app-map/scanner-source` (TypeScript compiler API) по каталогу находит: экспортируемые функции/классы/компоненты с JSDoc и обычными комментариями, файл и строку; роуты Elysia/Hono/Express; вызовы Drizzle/Prisma в обработчике; таблицы Drizzle (`pgTable` и пр.) и модели Prisma;
- формат карты — `formatVersion: 2` с разделом `code`; документы v1 читаются и поднимаются до v2 (`upgradeAppMapDocument`);
- CLI: `scan --code-dir <путь>` и команда `code --dir <путь>`;
- визуализатор: ноды-сервисы на холсте, в правой панели — роуты/функции с описанием из комментариев, таблицы и запросы в БД;
- тесты зовут настоящий сканер на фикстурах; карта по korbor и vpn-saas собрана и проверена.

**Вне рамок:** разбор графа вызовов между файлами (обработчик → репозиторий → БД через несколько модулей), связь экран → роут API по fetch-вызовам, точный префикс роутов из `.group()`/`prefix` в чужих файлах.
