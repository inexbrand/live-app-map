# 06 — Решения

- **formatVersion 2, а не расширение v1.** Раздел `code` и `kind: 'service'` меняют смысл документа; старые читатели не должны молча терять данные. Zod принимает 1 и 2, `parseAppMapDocument` поднимает v1 до v2 (`upgradeAppMapDocument` — только номер версии, раздела `code` в v1 нет).
- **`CodeModel.root`.** Карта экранов (`project.root` = приложение) и исходники (корень монорепо) — разные каталоги; пути раздела `code` считаются от `code.root`, панель экрана переводит `source.file` через `codeFileOfNode`.
- **TypeScript compiler API без внешних пакетов.** Своя `resolveModuleNameLiterals`: импорты в node_modules не разрешаются, workspace-пакеты — разрешаются. Скан korbor (2129 файлов) — ~5 с.
- **Вызовы БД через интерфейсы.** В korbor обработчики ходят в БД через порты (`repo.getById()`); без поиска реализаций (`function create…(): Repo { return {…} }`, `class … implements Repo`) вызовы БД были у 34 из 260 роутов, с ним — у 221. Ключ индекса — простое имя интерфейса (коллизии имён возможны, приемлемо).
- **Описание роута** — первое непустое: комментарий у вызова → JSDoc именованного обработчика → комментарий верхнего оператора с одним роутом → шапка файла с одним роутом. Комментарий не роута (общий для плагина с несколькими роутами) роуту не приписывается.
- **`inLoop`** — добавлено сверх ТЗ: N+1 запрещён правилами владельца, карта показывает его у роута.
- **Карты korbor/vpn-saas не коммитятся.** 4–7 МБ на карту (тысячи символов); vpn-saas — закрытый проект. Команды генерации — в README CLI; локальные карты в `public/maps/*.generated.liveappmap.json` в .gitignore.
- **Reassure не добавлен.** В визуализаторе нет ни Reassure, ни testing-library, тесты на bun test; e2e-путь экрана не менялся (новая панель открывается кликом по новой ноде). Поведение панели покрыто чистыми функциями `node-code`, `code-filter` и живой проверкой Playwright.
