# 06 — Решения

- Числа из данных korbor не зашивать: число роутов — из code.routes карты на диске, «целиком» — выше высоты «окна».
- Шаг «крошка вида снимает выбор» удалён: крошек нет, другого способа снять выбор роута в UI нет (openRoute принимает только id).
- Лист замечаний вместо шторки журнала в overlap: та же цель — открытый лист поверх всего, без наложений.
- Сервер трансляции держит набор каждой карты, сервису отдаёт объединение (mergeScreenSets): живой, если живой хоть у одной.
