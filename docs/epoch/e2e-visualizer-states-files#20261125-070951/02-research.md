# 02 — Причины

| Тест | Причина | Вид |
|---|---|---|
| overlap ×3 | Панели `.drawer`, `.diag-fab`, шторка журнала убраны по просьбе владельца (эпоха toolbar-shadcn-routes: «убрать кнопку Логи и статус», фокус Б3 — плашка .focus-bar); у шапки после shadcn нет класса .toolbar (data-testid=toolbar) | устаревший тест |
| node-scroll | id экранов карты проекта с префиксом приложения (`miniapp:route:/feed`); помощник stream-page находил страницу по префиксу адреса до #, у hash-роутера это любой экран мини-аппа; порог «целиком > 1500 px» зашит под старые данные ленты (сейчас 1106) | устаревший тест + ошибка помощника |
| node-scroll в параллели | сервер трансляции один на все карты, набор каждой карты заменял набор других: вторая вкладка закрывала экраны первой | поломка продукта |
| view-scroll ×2 | 314 роутов зашито, в карте 315; `.api-list__scroll`/`.api-tree` ушли в 7d123fd (вид API на shadcn, домены) | устаревший тест |
| ux-flows: роут, экран | крошки удалены по просьбе владельца (toolbar-shadcn-routes, Breadcrumbs.tsx удалён в bcd6cb7) | устаревший тест |
| ux-flows: тема | переключатель темы переехал в «Настройки» (там же; MapToolbar.test проверяет, что theme-toggle в шапке нет) | устаревший тест |
