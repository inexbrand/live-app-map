# Проверка построчно

## Чеклист brief

| Требование | Как проверено | Итог |
|---|---|---|
| Клик по экрану — по центру | вживую: transform scale 1.315, экран во всю высоту; canvas.test focusCamera | да |
| Остальные серые | вживую: 7 из 8 нод page-node--dim; canvas.test | да |
| Правая панель не нужна | StateInjectPanel.test: выбран экран — панели нет | да |
| Быстро дать правку «этот компонент — эта проблема» | вживую: клик по «Начать» → окно EmailField «Начать», Enter → файл created.json + shot.png (вырезка кнопки) | да |
| Правки сохраняются | файлы в LAM_FEEDBACK_DIR/comments/<id>/, SSE обновил лист без перезагрузки | да |
| Посмотреть все и отметить исправленными или нет | comments.test: группы по этапу, «Принять», «Не исправлено» с причиной, «Открыть снова», клавиши A/N | тестами; вживую — только список |
| Не грузить RAM/CPU/GPU | без опроса (SSE), снимок — вырезка кадра без захвата вкладки, окно и плашка — один rAF с transform | без замера FPS |

## Тесты: реальные вызовы?

- Ветки строятся настоящей foldThread; сервер — подмена fetch, которая дописывает событие и сворачивает заново.
- Трансляция — настоящий WebSocket (startFakeStream), сообщения страницы и pick.
- Ввод: screen-input.test шлёт pointer-события в настоящий ScreenView и читает, что дошло до сервера.
