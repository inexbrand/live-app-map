### «функции 0» и «таблицы 0» — причина найдена

- Счётчики берутся из `metadata` ноды сервиса (`apps/visualizer-spa/src/flow/ServiceNode.tsx`, функция `count`), а metadata пишет сканер (`packages/scanner-source/src/service-nodes.ts`, `codeServiceNodes`).
- В общей карте нода сервиса берётся из карты первой поверхности (`scripts/korbor-enrich.ts`, `addPage`: сервис добавляется один раз, без пересчёта), а раздел `code` — слитый из всех поверхностей. Отсюда в korbor-all у api symbols = 0 в metadata при 978 символах api в `code.symbols`; у всех сервисов, кроме miniapp (1), symbols = 0.
- «таблицы» считаются только как свои (`t.serviceId === s.id`): все 74 таблицы принадлежат @korbor/db, у api 0, хотя роуты api ходят в таблицы через `dbCalls`. Панель кода считает иначе — свои ∪ используемые роутами (`apps/visualizer-spa/src/lib/node-code.ts`, `selectNodeCode`). Два правила для одного числа.
- Что сделать: одна функция счётчиков сервиса (роуты, таблицы = свои ∪ из dbCalls, функции) в `@live-app-map/schema`; её зовут сканер и карточка на холсте (считать из `doc.code`, не из metadata); `korborAllDocument` пересчитывает metadata сервисов по слитому code.

### Домены api — данные есть, решение набросано

- 314 роутов api лежат в `apps/api/src/{modules,routes}/<домен>/…`, `apps/api/src/<домен>/plugin.ts` (disputes, reviews), `apps/api/src/routes/<файл>.ts` (files, error-reports, admin-metrics, webhooks).
- Правило без зашитого списка: путь роута от корня сервиса без `src`; каталог — контейнер, если роуты внутри него лежат в ≥2 дочерних каталогах (modules, routes); первый не-контейнер — домен (файл — по имени без расширения). Даёт около 30 доменов; routes/admin и modules/admin сливаются в admin.
- Рёбра «экран → сервис» строятся в `packages/cli/src/code-scan.ts` (`apiEdges`, `metadata.routeIds`) — их можно разложить по доменам по routeIds без пересканирования.
- Документ карты не менять (сравнение версий и экспорт увидят лишние ноды): ноды доменов выводить из `doc.code` при построении холста (`canvasView` в `apps/visualizer-spa/src/flow/AppMapCanvas.tsx`), выбор домена — в `selectNodeCode` (вид сервиса, суженный до роутов домена; панель `CodePanel` уже показывает описание, запросы в БД, таблицы, экраны). Нужна правка поиска ноды в `StateInjectPanel` (`index.nodesById`) и `selectPage` (`neighbors` по index).
- Существующая группировка вида API (`packages/graph/src/api-query.ts`, раздел/модуль по пути URL) — по пути, не по папкам; домены по папкам — новое правило.
