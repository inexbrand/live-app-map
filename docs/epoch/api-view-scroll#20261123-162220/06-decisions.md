# Решения

- Корень — размер строки грида вида, а не `overflow` колонок и не перехват колеса: строку задаёт общее правило `.api-view, .docs-view` (одно решение в одном месте), а не `min-height: 0` на `.api-list`.
- Тест не требует прокрутки, когда содержимое помещается (дерево API в 1600×1000, «Сравнение» без изменений в worktree): проверяет, что панель не выходит за окно, иначе — что колесо её сдвигает. Баг ловится по низу панели (21841px).
