# Decisions

- **Шлюз вместо query-токенов.** Приложения korbor берут вход из sessionStorage и кук; токен в
  адресе не работает для админки. Шлюз ставит значения до загрузки приложения.
- **Ячейка на ноду в имени хоста.** Общий origin давал общий sessionStorage: после входа
  экраны уводили друг друга. FNV-хэш id ноды → свой origin у каждого iframe.
- **Профили вне git, браузер видит только имена ключей.** Секреты не покидают dev-процесс.
- **Снимки JPEG в dev-процессе (headless Chromium).** Невидимый экран без iframe экономит
  память; снимок через тот же шлюз — под тем же профилем.
- **live 6 / warm 2.** По замеру: обзор 180 → 140 МБ кучи без потери читаемости.
- **Мини-карта осталась.** Она даёт перерасчёт раскладки на кадр, но ~0,1 мс; узкое место
  зума — композитор, не главный поток.
- **Вид «База данных» снимает холст целиком** — живые iframe не держат память, пока смотрят схему.
- **«целиком» — отдельная кнопка, а не пресет.** Пресеты ширины fixed; высота — независимое решение.
- **TanStack: обход импортов экрана до глубины 3, общие файлы (> ¼ экранов) отброшены,
  переход через виджет нескольких экранов — confidence low.** Без обхода admin давал 24
  перехода, с обходом без фильтра — каждый экран связан со всеми через оболочку.
