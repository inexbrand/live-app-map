| Трансляция (CDP screencast) вместо iframe | замер: зум 177–182 кадров/с, 0 долгих задач, вкладка 0,1–1,4 ядра против 97–134 и 2,3–5,4 | iframe с подменой (не даёт 180), монтирование React (один поток, нет изоляции ролей, Next не встроить) |
