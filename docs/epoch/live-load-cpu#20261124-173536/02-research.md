## Движение (measurements/motion*.json, profile-motion-nohide.txt)
- Основной поток визуализатора при зуме/панораме простаивает 10,2 из 12,8 с; JS ~0,5 с, из них dev-React ~0,3 с.
- Нагрузка — в процессах iframe и GPU: 2,3–4,5 ядра при 12 живых.
- Варианты при движении (display:none, visibility:hidden, свой слой will-change, ничего): зум 97–134 кадров/с,
  разброс между прогонами одного варианта больше разницы между вариантами. Панорама 177–180 кадров/с во всех.
- Вывод: 180 кадров/с на зуме при видимых живых iframe недостижимы — каждый iframe (отдельный процесс)
  перерастеризуется под новый масштаб на каждом кадре.
