# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| SPA гонять группами «файлы ↔ свои тесты» по lcov, а не весь пакет разом | Полный прогон mutator по SPA на каждый мутант гонял бы 1100+ тестов; группа гоняет 1–4 файла тестов | --mutate-all по всему apps/visualizer-spa |
| Выживших убивать тестами на собранных вручную данных (роут, таблица, документация), а не на карте korbor | Карта korbor даёт «есть раздел», но не крайние случаи: ровно предел, пустой список, нет сервиса | Искать в карте korbor подходящие объекты под каждый мутант |
| Canvas графа проверять журналом команд через узкий тип GraphCanvas | happy-dom не рисует; журнал команд ловит каждое изменённое число и цвет | Снимки картинок в e2e |
| Камеру графа вынести в graph-camera.ts | Чистые функции (fitCamera, centeredCamera, toWorld, nodeAt, zoomAt) тестируются без DOM; DocGraphCanvas.tsx стал 375 строк | Тестировать камеру через события мыши на холсте |
| Мёртвый код удалять, когда мутант показал недостижимую ветку и тип её исключает | Запасные значения warmPageIds?.size ?? 0, maxWarmIframes : 8 при обязательных полях store; ветка массива в textOf; проверка перед идемпотентным setUseTlsProxy | Писать тест на невозможное состояние |
| Остаток выживших не добивать | ?./?? на заведомо непустых значениях, начальные значения состояния, scrollIntoView, порядок уже отсортированного — эквивалентные мутанты, честного теста нет | Тесты, которые подменяют store несуществующими значениями |
