# План тестов

## Unit

- `minimapSize(bounds)` — пропорции раскладки вписаны в рамку, узкая раскладка не уже минимума.
- `listPathFor(routeId)` / подстановка параметров — по реальным routeIds из карты korbor.

## E2E / frontend

- e2e/minimap.e2e.ts (korbor-all, korbor-miniapp): SVG = контейнер, все ноды внутри, клик центрирует холст в точке клика, перетаскивание сдвигает рамку вьюпорта на столько же px, колесо меняет зум, рамка вьюпорта внутри контейнера при зуме 0.1/0.5/1.
- e2e/node-scroll.e2e.ts (живой korbor через шлюз): колесо над /feed в «окне» прокручивает .tab-canvas__scroll, transform холста не меняется; колесо по пустому холсту зумит; «целиком» — внутри iframe нет переполнения, метки «обрезано» нет; «окно» — метка есть.
