## Как устроено сейчас

- `AppMapCanvas.tsx`: `<MiniMap pannable zoomable />` без размеров → React Flow рисует SVG 200×150 и считает масштаб перетаскивания от 200×150.
- `global.css`: `.react-flow__minimap { width:140px!important; height:100px!important }` + `contain: strict` → контейнер 140×100 режет SVG (видно 70%×67%), рамка вьюпорта и правые/нижние ноды срезаны, пропорции drag не совпадают.
- Замер на korbor-all: viewBox 43155×32880, ноды в полосе 20 px шириной; 66 из 115 нод в границах контейнера. Клик по мини-карте не меняет transform холста.
- Раскладка korbor-all — столбец групп 4208×30809 (рамка группы 4176×21902), рамки групп рисуются на мини-карте той же заливкой, что экраны — сплошная серая полоса.
- Ноды экранов: iframe с `pointer-events: none` (кроме режима взаимодействия по двойному клику) → колесо над нодой всегда зумит холст, страницу в «окне» не прокрутить.
- Мини-апп korbor (/feed, 390×844): прокручивается не body, а `.tab-canvas__scroll` (scrollHeight 5838, padding-bottom 112 под нижнее меню). Скрипт шлюза считает высоту контента как body + переполнение внутреннего контейнера → 5838, «целиком» даёт iframe 5838.
- vacancies/:id: скан подставляет `id: 'demo'` (общий словарь по имени параметра) → API отвечает 404/400, экран пустой. Живой API: `GET /api/v1/recruiter/vacancies` (рекрутер), `/api/v1/employer/vacancies` (свои вакансии клиента), `/api/v1/admin/vacancies` — первые id реальные; вход — dev dogfood (`/api/v1/dev/dogfood/session`), у мини-аппа initData → `POST /api/v1/auth/telegram/miniapp` → Bearer.
- Карта знает вызовы API экрана (рёбра kind=api, metadata.routeIds: `GET /api/v1/recruiter/vacancies/:vacancyId`) → список той же сущности — тот же путь без последнего `/:param`.

## Что менять

- MiniMap: размер из пропорций раскладки (чистая функция), style/props вместо CSS, nodeColor/nodeStrokeColor, onClick → setCenter.
- CSS: убрать !important размеры и contain: strict у мини-карты.
- Колесо: обработчик на теле ноды пересылает колесо в iframe (postMessage → скрипт шлюза прокручивает элемент под курсором), не пуская его в холст.
- Параметры маршрута: сервер визуализатора по профилю экрана берёт первый id из списка API, клиент подставляет его в адрес.
