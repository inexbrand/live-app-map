# Brief

## Цель

Мини-карта, прокрутка экранов мини-аппа в нодах и экран vacancies/:id с реальными данными — на живом korbor.

## Готово когда

- [ ] Мини-карта: размер через пропсы MiniMap (без !important и contain: strict), SVG целиком внутри контейнера, все ноды в границах.
- [ ] Клик по мини-карте центрирует холст в точке клика.
- [ ] Ноды мини-карты читаемы: рамки групп контуром, экраны цветом группы; рамка вьюпорта точна при любом зуме.
- [ ] Перетаскивание и колесо по мини-карте пропорциональны (рамка идёт за курсором).
- [ ] Колесо над живым экраном с прокруткой («окно») прокручивает страницу, вне экрана — холст; Ctrl/⌘+колесо — всегда зум холста.
- [ ] «Целиком»: нода по высоте страницы, контент не уходит под нижнее меню, метка «обрезано» только когда видно не всё.
- [ ] vacancies/:id (и другие экраны с параметрами) открываются с реальным id из API korbor под профилем экрана.
- [ ] e2e Playwright на мини-карту и прокрутку, скриншоты до/после в screens/.

## Вне scope

- Область PR #4 (шлюз, профили, снимки, зум-производительность) — только точечные правки, нужные этой задаче.
- Раскладка korbor-all (высокий столбец групп) — не меняю, мини-карта подстраивается под её пропорции.
