# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| Размер мини-карты — style MiniMap по пропорциям раскладки (до 240×180, сторона не меньше 56) | React Flow считает масштаб SVG и drag от style; пропорции убирают пустой фон | CSS-размер (обрезка), фиксированный 168×112 из PR #4 (korbor-all — полоса на пустом фоне) |
| offsetScale 0 | drag React Flow не учитывает поля viewBox — рамка отставала от курсора на ~4 % (2,8 px на 30) | поля по умолчанию |
| Цвета нод пропсами (nodeColor), рамки групп — без заливки | одно место решения, проверяемо в e2e | CSS-классы с !important |
| Колесо → postMessage {lam:'wheel'} в скрипт шлюза, только когда страница длиннее окна | iframe без pointer-events (клики выбирают ноду); скрипт прокручивает тот контейнер, что под курсором | pointer-events: auto (ломает выбор и перетаскивание нод), прокрутка всегда (колесо над нодой без прокрутки потеряло бы зум) |
| Ctrl/⌘+колесо всегда — холст | щипок тачпада = зум холста | — |
| Параметры маршрута — во время показа, под профилем экрана | вакансия клиента видна только ему, рекрутеру — опубликованные; id из скана не подходит всем профилям | id при скане (не совпадёт с профилем визуализатора) |
| Список сущности = GET-роут экрана без последнего `/:param`; запасной — GET-роуты раздела code | рёбра экран→API уже в карте; у админки сканер вызовы не сопоставил | ручная таблица маршрут→эндпоинт |
| Merge origin/master вместо rebase | ветка уже запушена, force-push запрещён правилами | rebase + force-push |
