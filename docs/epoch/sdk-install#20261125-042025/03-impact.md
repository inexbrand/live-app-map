# Влияние и риски

- package.json sdk: добавляются только scripts; exports на src не меняются → монорепо не затронут.
- commands.ts: строка регистрации init — пересечение с зоной project (согласуется сообщением).
- install.sh выполняется в чужом проекте: не трогает существующие config.ts/states.ts (идемпотентно), .gitignore только дописывает строку.
- Нет релиза sdk-v* → init без --tarball падает с понятной ошибкой (не подставляет выдуманный URL).
- Скилл перезаписывается при повторной установке (это наш файл; обновление скилла — желаемо).
