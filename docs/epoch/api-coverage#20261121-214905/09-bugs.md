## Известные ограничения (не баг задачи, вынесено)

- URL-построители без вызова (`exportUrl()` → `<a href>` для export.csv) не считаются вызовом: это ссылка на скачивание, а не запрос из кода.
- `/api/v1/${surface}/support/…` в mobile: параметр на месте литерального сегмента не сопоставляется с двумя роутами; mobile в карте без экранов, на «вызываются экранами» не влияет.
- `POST /api/v1/activity/batch`: путь передаётся библиотеке телеметрии конфигом (`endpoint`), отправку делает пакет — сканер такую передачу не прослеживает.
