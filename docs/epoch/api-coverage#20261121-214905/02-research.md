## Почему связей мало (причины по коду)
1. **Админка korbor**: `route-config.ts` — только данные (`def(id, path, …)`), компонент выбирает
   `switch (section)` в `app/routing/operational.tsx`/`governance.tsx`. `rrScreenRoots` не находит
   объект с `element` → корней нет → 0 из 57 экранов.
2. **Табы мини-аппа korbor**: `tabRoute('feed', 'feed')` → `{ id, path, element: null }`; экран рисует
   шелл по id из `ROUTE_MODULE_LOADERS`. Путь объекта — параметр фабрики → объект не распознан.
3. **Сторы-фабрики**: `useMemo(() => createVacanciesStore(api))` — тип стора не виден (React без типов),
   а фабрики с ≥ 2 методами обход пропускал целиком → вызовы стора не доходили до экрана.
4. **Метод по имени** (тип получателя не виден) брал реализацию из любого интерфейса с таким
   методом: `store.load()` вакансий цеплял `load` стора выплат.
5. **Алиасы путей** `@/…` из `tsconfig.paths` не разрешались (277 файлов в admin/miniapp korbor).
6. **TanStack (vpn-saas)**: файл экрана — сама страница, а сканер искал в нём объект роута RR → пусто;
   данные часто грузит `loader` в `app/routes.tsx`; один файл страницы на два маршрута считался конфигом.
