# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| Корни экрана: tabRoute/загрузчик по id, switch-диспетчер раздела (≥ 2 раздела одного конфига), файл страницы, loader TanStack из routeFile | у админки korbor и вкладок мини-аппа в конфиге нет компонента | сопоставлять экраны по имени файла — ложные связи |
| Фабрика-стор обходится целиком, если её достигает ≤ max(2, ¼) экранов сервиса | стор `createXStore(api)` под useMemo — тип не виден, методы зовутся по имени | обходить всегда — общий клиент дал бы все роуты каждому экрану |
| Метод по имени — только из фабрики, которую достиг этот экран, или внедрённой (никем не достигнутой) | экран вакансий цеплял `load` стора выплат | имя без ограничений — ложные связи (тест падал) |
| Алиасы `paths` ближайшего tsconfig | vpn-saas импортирует через `@/` | — |
| Параметр-адрес перед литералом `/…` — origin | `${origin}/api/x` в мини-аппе vpn | — |
| fetch, пришедший параметром (fetchWithAuth), — как fetch; `api.getRaw(путь)` — вызов, только если первый аргумент — литерал пути | сторы споров/очереди/поддержки админки korbor | любое имя get* — `api.getUser(id)` дал бы мусор |
| Описание из кода собирается в graph (`routeAutoDoc`) при показе, а не хранится в карте | одно место решения для UI и MCP; карта хранит только факты (`response`) | писать текст в карту — устаревает вместе со сканером |
| «Без описания» — только по авторским, «Без экранов» — отдельный фильтр с причиной | бриф | — |
| Причина «без экранов»: unreached / other-client / no-caller (+ бот, вебхук, вход, internal, cron, dev по пути и файлу) | честный список «не вызываются в принципе» | одна общая фраза |
