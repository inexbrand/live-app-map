# Решения

## Принято

| Решение | Почему | Альтернатива отвергнута |
|---|---|---|
| Версии карты — история файла в git (`git log`/`git show` по хешу) плюс свежий скан во временный каталог | Карты уже лежат в git; второй формат хранения снимков не нужен | Отдельное хранилище снимков: дублирует git |
| Сравнение считается в пакете graph (`diffMaps`), вид только раскладывает по разделам | Одна логика для CLI `diff` и интерфейса | Сравнение внутри React-компонента |
| Сдвиг строки роута (location) не считается изменением | Иначе любая правка файла даёт «изменились все роуты» | Сравнение всего объекта |
| Запись 09-bugs — только через dev-сервер, только `docs/epoch/*/09-bugs.md`, только с локального origin, с подтверждением в UI, атомарно через временный файл | Правка файлов на диске из браузера — опасная операция | Запись любого пути; запись без подтверждения |
| Правка пункта на месте: чекбокс переключается, иначе блок переносится между разделами Open/Closed; несовпадение текста строки — 409 | Файл мог измениться с момента чтения | Перезапись по номеру строки без проверки |
| Схема входа роута — дерево полей с необязательностью и правилами; константы схем разворачиваются по имени, глубина до 8 | korbor собирает схемы из констант; «Elysia t» ничего не говорил | Текст выражения как есть |
| Повтор sample-ids: 3 с, 15 с, 60 с, затем стоп; пустой ответ — не сбой | Шлюз отвечает 429 при всплеске; бесконечные повторы нагружают korbor | Повтор только по перезагрузке страницы (как было) |
| Ширина ряда крупной группы — по площади нод (2:1), кусок связной компоненты — LR/TB/полки, ближайший к 2:1 | Звезда «меню → 30 экранов» в LR давала столбец 3940×26736 | Поднять общий предел ширины: раздувает мелкие группы |
| Не чиним `/api/v1/${surface}/…` в mobile | Значение `surface` известно только по типу `ChatSurface`; привязка к обоим роутам — догадка; mobile без экранов в карте | Сопоставлять параметр с любым литеральным сегментом |
| Не чиним `POST /api/v1/activity/batch` | URL уходит конфигом в стороннюю библиотеку телеметрии; запрос шлёт её код | Особый случай под одну библиотеку |
| Не чиним экраны без списка для параметра (chat/[candidateId], call/[callId], legal/[code], register/[step] …) | У их API нет списка той же сущности — реальный id взять неоткуда; нужен источник примеров на экран в профиле | Подставлять первый попавшийся id другой сущности |
| route-params.e2e находит экран поиском | Тест зависел от места ноды на холсте; после правки раскладки нода вне кадра | Подогнать раскладку под тест |
