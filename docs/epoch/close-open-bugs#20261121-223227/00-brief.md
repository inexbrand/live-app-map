# Brief

## Цель

Закрыть открытые пункты 09-bugs эпох ux-overhaul, api-coverage, e2e-green, minimap-overflow: сравнение карт в интерфейсе, отметка пункта 09-bugs из вида «Документация» с записью в markdown, полная схема входа роута вместо «Elysia t», остальные мелкие баги — починить или обосновать.

## Готово когда

- [ ] Вид «Сравнение»: две версии карты (git-история файла, файл на диске, открытая карта, свежий скан) → добавлено / пропало / изменилось по экранам, роутам, таблицам, связям; e2e.
- [ ] «Документация»: отметить пункт 09-bugs закрытым/открытым → правка файла на диске через dev-сервер после подтверждения, готовность эпохи пересчитана; e2e на временной копии.
- [ ] Сканер: t.Optional(t.Object(…)), вложенные объекты, ссылки на схемы, t.Record/t.Unknown → поля, типы, обязательность; карточка роута показывает дерево полей.
- [ ] Селект карт после импорта показывает файл; повтор неудачного sample-ids; прочие пункты — исправлены или обоснованы.
- [ ] typecheck чистый, весь e2e зелёный, скриншоты, 09-bugs четырёх эпох закрыты; PR слит.

## Вне scope

- Сканер других фреймворков, кроме исправления схем Elysia/zod.
