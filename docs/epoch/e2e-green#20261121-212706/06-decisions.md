# Decisions

- Шапку не переносим на вторую строку, а сворачиваем вкладки вида до иконок < 1280 px: вторая строка тоже опускала бы панели.
- Счёт экранов в e2e — по мини-карте, а не отключением `onlyRenderVisibleElements`: виртуализация холста — решение бюджета памяти.
- Ожидаемое число экранов в тестах не зашито: из подписи каталога (smoke) и из файла карты (import-clear).
- Каталог считает экраны через `liveAppMapToAppMap` — одно правило «что такое экран» (kind=page) для обоих форматов.
- Кэш Bearer по ключу apiBase|initData до exp−60 с; одновременные запросы ждут один обмен; отказ не запоминается. Админке обмен не нужен.
