- Нельзя писать файл в REPL через `cat > file < /dev/stdin`: stdin нет, файл обрезается до 0 байт, команда висит. Правильно: write во временный файл в scratchpad, потом cp.
- Модули, которые импортирует vite.config (middleware, scanner-docs), dev-сервер держит в старой версии — после правки перезапускать vite (убить процессы на своих портах и запустить заново).
- `cd` внутри шелл-шаблона REPL меняет рабочий каталог всей сессии (следующие команды уходят в него). Каталог задавать через `.cwd(dir)`, `-p` или абсолютные пути, без cd.
- Текст памяти с обратными кавычками и `$` писать через write(), не через шелл-шаблон: иначе куски раскрываются и файл портится.
- Карта, собранная `cli code` в каталоге без приложений (0 нод), не проходит валидацию при импорте. Временному проекту в e2e нужен сервис (например, apps/web).

**Why:** первая ошибка обнулила MapToolbar.tsx; вторая давала «устаревшее» поведение в e2e; cd увёл сессию в apps/visualizer-spa.

**How to apply:** см. [[visualizer-ux-overhaul-lessons]], [[large-file-edit-tooling]].
